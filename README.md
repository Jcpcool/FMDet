# FMDet
FMDet: A Frog-Inspired Motion-Perception Network for Tiny Drone Detection
Official repository for FMDet, A Frog-Inspired Motion-Perception Network for Tiny Drone Detection

FMDet combines explicit motion representations with appearance features
through progressive cooperation to improve tiny drone detection.
